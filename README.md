# Uitdager 🏆

Een maandelijkse challenge app voor Manon & Melvin.

## Functies

- 🔐 PIN-login (Manon: 1993, Melvin: 2711)
- 📝 Challenge aanmaken & goedkeuren (beiden moeten akkoord gaan)
- 🎨 Candy Crush-stijl kaart (gedeelde voortgang)
- ✅ Dagelijkse activiteiten afvinken
- ⏱ Ingebouwde timer voor geminuutde activiteiten
- 🔔 Dagelijkse herinneringen via push notificaties
- 📊 Leuke statistieken pagina
- ⚡ Real-time sync tussen beide gebruikers

## Setup

```bash
npm install
npx expo start
```

Scan de QR-code met de **Expo Go** app op je iPhone.

## Tech Stack

- React Native + Expo
- Supabase (database + real-time)
- expo-router (navigatie)
- expo-notifications (push notificaties)
